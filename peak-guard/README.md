# API 高峰保护（dsh-peak-guard）

在 DeepSeek API 进入高峰计价前几分钟，自动让 agent **保存进度、停止工作**，并在高峰期间默认不接新活；你只要说一句「继续」或输入 `/peak continue`，就照常工作。

## 它怎么工作

DeepSeek 官方计价：**北京时间周一至周五 09:00–12:00、14:00–18:00 为高峰时段**（单价翻倍），其余时段、周末和中国法定节假日全天空闲。

插件按本机时钟判断三个阶段，并把这行提示注入模型的运行时上下文（每个 agent 一步一次，内容不变时不会重复消耗 token）：

| 阶段 | 触发 | agent 收到什么 |
| --- | --- | --- |
| 收尾 | 高峰开始前 `leadMinutes`（默认 3）分钟 | 停止开新活 → 把进度写进 `PEAK_HANDOFF.md` → 回你一句话并停手 |
| 高峰 | 高峰窗口内 | 默认暂停；除非你明确说「继续」，否则只回暂停说明 |
| 空闲 | 其余时间 | 什么都不注入（旧提示会被清掉） |

`PEAK_HANDOFF.md` 写在当前会话的工作目录，内容包括：任务目标 / 已完成 / 进行中 / 下一步 / 关键文件与命令。下一个空闲时段接着干时，直接让它读这个文件就行。

## 输入框下方的状态条

插件在输入框下方渲染一行小字，实时显示当前处于哪个阶段、距离下次切换还有多久：

| 显示 | 含义 |
| --- | --- |
| 🟢 空闲 · 距高峰 4 分钟 | 空闲时段，4 分钟后进入高峰（含 3 分钟收尾窗口） |
| 🟡 收尾中 · 距高峰 2 分钟 | 正在收尾，再过 2 分钟进高峰 |
| 🔴 高峰中 · 剩余 1 小时 58 分 | 高峰期，暂停中 |

颜色取自主题的状态色（success / warn / error），跟随浅色/深色主题。鼠标悬停能看到本次高峰的具体起止时间和交接文件路径。

状态由 Host 的 `GET /peak-guard/status` 提供，前端每 15 秒对齐一次、每秒本地走秒，所以倒计时是连续的。

## 不冲突：随时可以继续

- 高峰期回一句「**继续**」「接着干」「别停」等（消息要短，插件靠这个区分是不是真的让你继续），本窗口的暂停立即解除，直到该高峰窗口结束。
- 也可以输入 `/peak continue`，效果相同。
- `/peak off` 关闭本会话的保护，`/peak on` 恢复。
- 每个高峰窗口单独计算：解除只对当前窗口有效，下一个高峰会重新提醒。

## 命令

```
/peak            # 状态：现在空闲还是高峰、下次高峰还有多久、交接文件路径
/peak continue   # 解除本轮高峰暂停
/peak off        # 本会话关闭保护
/peak on         # 本会话恢复保护
/peak test       # 演练：立即触发一次「高峰前收尾」提示（3 分钟后自动结束）
```

## 配置

改 `cordis.patch.yml` 里 `peak-guard` 行的 `config`：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关 |
| `leadMinutes` | `3` | 提前几分钟开始收尾；觉得不够可以改大 |
| `peakWindows` | `['09:00-12:00', '14:00-18:00']` | 高峰窗口，可多段 |
| `workdays` | `[1,2,3,4,5]` | 高峰只在周几（0=周日） |
| `utcOffsetMinutes` | `480` | 北京时间 UTC+8 |
| `handoffFile` | `PEAK_HANDOFF.md` | 交接文件名（相对工作目录） |
| `holidays` | 2026 年法定节假日 | `YYYY-MM-DD` 列表，节假日全天空闲；跨年时记得更新 |

调休上班的周末按官方规则算作空闲（官方只认「周一至周五且非法定节假日」）。

## 安装

```
dsh plugin --profile <profile> add <此目录的绝对路径>
```

或在本会话里用插件管理器安装这个目录。安装后重启 DSH 才会在所有会话生效；当前会话会通过 HMR 立即生效。

## 已知边界

- 「停止」是**软约束**：插件通过注入上下文要求 agent 停手，而不是强行中断回合。这样做是为了你一句「继续」就能无损恢复，也避免在写文件的中途被切断。
- 如果一步工具调用本身就跑了很久，可能错过提前量；把 `leadMinutes` 调大即可。
- 子 agent（subagent）也会收到同样的保护提示。
